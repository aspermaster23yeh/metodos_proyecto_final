Ajuste de Curva de Carga de Batería Li-ion mediante Regresión No Lineal
1. Introducción
En la era de la movilidad digital, la eficiencia de las baterías de iones de litio (Li-ion) es fundamental para el funcionamiento de dispositivos electrónicos. Sin embargo, el proceso de carga no es uniforme, ya que está gobernado por principios electroquímicos y sistemas de gestión de batería (BMS).
Este proyecto analiza experimentalmente el comportamiento de carga de un smartphone mediante la recolección de datos cada 5 minutos. A través de técnicas de regresión matemática y ajuste de curvas, se busca modelar este fenómeno y explicar por qué la carga es más rápida al inicio que al final.
2. Objetivos
Objetivo General
Modelar matemáticamente el proceso de carga de una batería para predecir el tiempo total de carga y analizar su comportamiento no lineal.
Objetivos Específicos
* Registrar el porcentaje de batería cada 5 minutos.
* Identificar fases de carga: rápida (CC) y lenta (CV).
* Ajustar modelos matemáticos (lineal, logístico, exponencial).
* Evaluar el modelo mediante el coeficiente de determinación R2R^2R2.
3. Marco Teórico
3.1 Protocolo de Carga CC-CV

* Voltaje Constante (CV): desaceleración progresiva (80%–100%).

Parte 6 — El modelo matemático en JavaScript


const L  = 100;       // capacidad máxima (100%)
const k  = 0.11850;   // tasa de crecimiento de la curva
const t0 = 23.85;     // punto de inflexión (donde la carga sube más rápido)


function C(t)  { return L / (1 + Math.exp(-k * (t - t0))); }
function Cp(t) { const e = Math.exp(-k*(t-t0)); return L * k * e / Math.pow(1+e, 2); }
	Aquí está el corazón matemático. Se definen dos funciones:
         * C(t) — la curva sigmoidal que modela cómo carga la batería con el tiempo. Devuelve el porcentaje de carga en el minuto t.
         * Cp(t) — la derivada de C(t), necesaria para Newton-Raphson. Indica qué tan rápido está cambiando la carga en ese instante.
Los parámetros L, k y t0 fueron calculados previamente con gradiente descendente (se menciona en el comentario).
Parte 7 — El algoritmo Newton-Raphson


endfunction newtonRaphson(target, t_init=26, tol=1e-8, maxIter=50) {
  const steps = [];
  let t = t_init;


  for (let n = 0; n < maxIter; n++) {
    const ft  = C(t) - target;   // f(t) = C(t) - objetivo
    const fpt = Cp(t);            // f'(t)


    if (Math.abs(fpt) < 1e-14) break;  // si la derivada es casi 0, para


    const t_new = t - ft / fpt;        // fórmula principal N-R
    const delta = Math.abs(t_new - t); // error entre iteración y la siguiente


    steps.push({ n, t, ft, fpt, t_new, delta }); // guarda cada paso


    t = t_new;
    if (delta < tol) break; // convergió → termina
  }


  return { t, steps, converged: steps[steps.length-1].delta < tol };
}
	Esta función implementa el método como tal. Parte de un tiempo inicial t_init = 26 min y en cada iteración aplica la fórmula t_nuevo = t - f(t)/f'(t). Guarda cada paso en un arreglo steps para luego mostrarlo en la tabla. Para cuando el error es menor que 1e-8 (convergencia).

14. Conclusiones
         * La carga de baterías es un proceso no lineal (sigmoide).
         * El modelo logístico es adecuado teóricamente.
         * Newton-Raphson:
         * ✔ Funciona en ecuaciones simples
         * ✖ Puede fallar en sistemas complejos
         * Los errores NaN invalidan el modelo final.
15. Recomendaciones
         * Usar métodos más robustos:
         * Levenberg-Marquardt
         * Gradiente descendente
         * Eliminar datos extremos
         * Usar software especializado (Python, MATLAB)
16. Conclusión General
El comportamiento de carga de una batería Li-ion sigue un modelo sigmoide influenciado por factores físicos y electrónicos. Aunque el modelo logístico describe correctamente la tendencia, su implementación mediante Newton-Raphson requiere condiciones numéricas estables para evitar errores y obtener resultados confiables.
